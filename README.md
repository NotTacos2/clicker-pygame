# Brownie Clicker
This game is a clicker game inspired by cookie clicker, basically you have to click brownie to gain points and seeing how many you can click.

## Features:
- Endless cookie clicking
- Save data with json
- Settings page (with save reset)
- Stats page
- Shop page

# I would recommend using windows to play this game since it uses ctypes for message box, you can remove the ctypes and message box warning in the code if you want to play on other os
